# Jamie Dean — portfolio

Static site at https://aspirations.pages.dev, generated by `node build.mjs` from `content/`.

- `node build.mjs` → `dist/` (fails on forbidden words)
- `node --test "test/*.test.mjs"` · `node test/links.mjs` · `node test/smoke.mjs`
- `node tools/photos.mjs` — resize photos from the old Hugo site
- `node tools/shoot.mjs [name…]` — re-capture app screenshots (needs `shots.local.json`, git-ignored)

Deploys on push to `main` (Cloudflare Pages, git-connected). Design notes in `docs/superpowers/`.
