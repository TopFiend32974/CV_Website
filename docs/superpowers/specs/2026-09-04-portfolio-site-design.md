## Screenshots

`tools/shoot.mjs` runs Playwright (Chromium, already installed under `~/.cache/ms-playwright`)
from Origin at a fixed 1440×900 viewport, dark colour scheme, and writes PNGs to `assets/shots/`.

- **Targets live in `shots.local.json`, which is git-ignored.** The deploy repo is **public**
  (see Deploy), so tailnet hostnames must never be committed. A committed `shots.example.json`
  documents the shape with placeholder hosts.
- **Public targets:** novarapro.co.uk, phillfab.pages.dev, immys-moorland-ponies.pages.dev.
- **Tailnet targets:** Lyra, Obol, Apexio dashboard, Vesta, Odysseus, Forgejo, Grafana. All
  reachable from Origin over Tailscale; the script does not run anywhere else.
- **Redaction is per target, in the script, before capture:** Obol blurs every element whose
  text matches a money pattern (`£`, digits with two decimals) via injected CSS; Lyra is shot on
  a single-album view chosen by Jamie rather than the library home; Forgejo is shot on the
  explore page, not a repo list. The Vortex hostname is masked in any address-bar-like UI chrome.
- Captures are committed PNGs. **Jamie reviews the set before the first deploy** (`review/`
  contact sheet, untracked). Re-running the script is the whole refresh procedure.

## Photos

The 47 source photos (bikes, GPUs, project PNGs) stay in `CV_Website-main/content/` as the
originals. `tools/photos.sh` copies them into `assets/photos/` resized to a 1600 px long edge and
re-encoded (JPEG q82 for photographs, PNG for screenshots) — ImageMagick is on Origin. The
current site ships 100 MB of images with several at 5 MB; the target is under 15 MB total. File
names lose the `image copy 3.png` pattern and become `zx12r-black-1.jpg`.

## Build

```
portfolio/
  build.mjs            # Node 22, no deps: reads content/, renders templates/, writes dist/
  content/
    projects.json
    pages/*.md          # about, experience, skills, hobbies, contact — a tiny md→html subset
    site.json           # name, tagline, links, employer line, footer mark
  templates/*.html      # layout + one per page type; ${} substitution, no template engine
  assets/
    site.css            # one file
    shots/  photos/  logo/
  tools/shoot.mjs  tools/photos.sh
  test/links.mjs  test/smoke.mjs
  dist/                 # generated, git-ignored
```

The markdown subset is deliberately small: headings, paragraphs, bold, links, lists, images.
Anything else is written as HTML in the page file. No client-side JS except a theme toggle.

## Design direction

Dark ground, the gold accent Jamie already chose (`#FFD700` / `#FFA500`), but used sparingly.
A large display typeface for the name and section titles, a readable body face, both from Google
Fonts with system fallbacks. Home is a hero plus a three-up of the headline projects. Projects are
cards with the screenshot on top, blurb, language chips and a status pill. Hobbies gets three
distinct treatments: bikes as a full-bleed photo grid with captions, GPUs as a horizontal
chronological timeline (7770 → 7900 XTX), gym as a stat row. Responsive down to a phone; no
scroll-jacking, no autoplay. The `frontend-design` skill is invoked at build time for the visual
pass; this spec fixes structure, not pixels.

## Testing

- `node build.mjs` is deterministic; the same inputs produce a byte-identical `dist/`.
- `node test/links.mjs` walks `dist/` and fails on any internal `href`, `src` or CSS `url()` that
  does not resolve to a file, and on any external link to a GitHub repo that is not public (checked
  once via `gh api`, cached).
- `node test/smoke.mjs` serves `dist/` locally, opens every page in Playwright at desktop and phone
  widths, and fails on any console error or non-2xx request. It saves one screenshot per page to
  `review/` (untracked) for Jamie to eyeball.
- Forbidden-word check: the build fails if `dist/` contains any of a short list (arr names,
  "torrent", "tailscale", "vortex.tail").
